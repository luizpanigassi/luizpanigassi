## 🎮 Capstone: Bullet Overflow

A 1v1 online top-down shooter built in **Godot 4.4** that runs in the browser (HTML export). It was my *ft_transcendence* at 42SP.

**My part:** the entire game client. The backend (OAuth login, PostgreSQL leaderboard) was built by my teammates.

- Real-time multiplayer over WebSockets: client-side prediction, server reconciliation, entity sync
- Hunted down the desync bugs that make online games feel broken: powerup sync, dual-authority screen wrap, phantom deceleration on remote players
- Pixel art pipeline for characters (SNES-style spritesheets and animation layouts in Godot)
